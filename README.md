# Your Python Journey

An interactive Streamlit app for exploring Python topics, learning styles, tools, and project ideas.

## Features

- Adjust your coding experience with a slider.
- Choose a Python topic and view a short explanation.
- Select a preferred learning style and get a resource recommendation.
- Track the tools and libraries you use.
- Generate project ideas from a keyword.
- View a personalized progress summary.

## Setup

Create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Install the dependency:

```bash
python -m pip install -r requirements.txt
```

## Run the app

```bash
streamlit run explore.py
```

Streamlit will provide a local URL in the terminal, usually `http://localhost:8501`.
